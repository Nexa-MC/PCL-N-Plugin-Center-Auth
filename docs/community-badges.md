# 公开资料铭牌

- `bilibili-level`「b站来的」：已通过个性签名挑战绑定 B 站，可信公开等级为 Lv6。
- `bilibili-million`「小黄标」：同一绑定账户的可信公开粉丝数 ≥ 1,000,000。
- `nexacl-contributor`「走向明天」：通过 GitHub OAuth 绑定的数字用户 ID 出现在 `Nexa-MC/NexaCL` 官方公开 contributors API 中，`type=User` 且 `contributions≥1`。不以邮箱、昵称、客户端提供的用户名、未合并 PR 或组织成员身份代替。

`GET /auth/v1/account/level` 按需刷新后返回铭牌。B 站每个绑定账户至少间隔 15 分钟，沿用 Browser Rendering 可信读取和全局限流／风控退避；刷新不会改变账户所有权。签名核验成功即保存首次资料。迁移仅回填仍有匹配成功挑战记录的既有绑定；缺少所有权证据的历史绑定需要重新核验。

GitHub 使用全站共享的完整列表快照，正常间隔一小时，失败至少间隔 15 分钟。固定仓库和分页地址，不跟随重定向，最多十页、每页一百项、总超时十秒；失败或超出预算不提交部分列表。不使用用户 PAT。GitHub 自身可能缓存贡献者、按其默认分支提交归属规则统计，并有贡献者作者缓存范围限制；本铭牌以其公开列表为准，不能覆盖所有形式的社区贡献。

旧人工核验记录仍保留用于历史导出，但不再用于授予这些标；人工核验接口对它们返回 422。解绑立即失去对应资格；B 站资料刷新不得跨越解绑或换绑写入，GitHub 资格始终与当前绑定的数字 ID 比较。公开统计下降后，下一次成功同步按新值重新判定。

临时上游失败保留上次成功数据，界面显示同步失败和最近核验时间；没有成功数据时不授予。页面的“刷新”受上述缓存间隔约束，不承诺实时更新。这些额外铭牌不替代等级。
