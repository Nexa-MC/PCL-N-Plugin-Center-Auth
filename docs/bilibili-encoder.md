# 文学签名编码器与 1,000 条样本检查

当前绑定版本：`bili-zh80-en64-v2`。每次提供两句中文和两句英文，用户选中其中一句后，其余候选立即失效。句子由固定词库、语义规则和确定性编码生成，不在线调用模型或翻译服务；页面切换语言不修改生成的句子。

## 检查结果

本轮生成 **1,000 条**非生产样本：中文 500 条、英文 500 条，每个候选位置 250 条。所有样本通过词法 / 语义规则、长度、Unicode 规范形式、无控制或不可见字符、rank/unrank 往返检查；样本中 **0 重复**。中文固定 39 字符，英文 61–70 字符，均不超过 70 字符。样本不能直接用于账户绑定。

检查发现并修正了“辽阔栈道”、进入石桥 / 山巅、岛屿流动、露水鸣响、颜色修饰不合适的动物、相同词根反复拼接等问题。英文使用逐类别动词白名单、修饰语限制和同句四个不同主体的规则；中文增加建筑道路与进入类动作限制。自然度判断覆盖这些样本与规则，并不把所有合法组合都视为已获独立人工文学审校。

## 熵值：中文 80 bit，英文 64 bit

中文每条使用独立的 10 字节随机量；英文使用独立的 8 字节随机量。两者均来自密码学随机源。英文按未确认平台上限时的保守 **70 字符**限制计算，采用原规划“至少 64 bit”的下限；**不声称英文达到推荐的 80 bit**。

每个中文候选空间的真实合法句子数如下，已经扣除语义禁配：

| 首词 | 合法句子数 |
| --- | ---: |
| 清晨 | 18866076154478261996535808 |
| 黄昏 | 20128627290220614959759360 |

它们都超过 `2^80 = 1208925819614629174706176`；各候选实际映射 `2^80` 个等概率输出。

英文合法句子总数为 **40489922855434647216**。该数已经扣除所有白名单、70 字符限制以及重复主体。按 rank 奇偶拆为两个互斥子空间，各有 **20244961427717323608** 个句子，均超过 `2^64 = 18446744073709551616`；每个英文候选实际映射 `2^64` 个等概率输出。

`nonce -> 奇数仿射置换 mod 2^k -> floor(permutedNonce × C / 2^k) -> unrank`。奇数置换在 `2^k` 上是双射；因 `C >= 2^k`，不同随机量的 rank 至少差 1，映射为单射。中文首词子空间不同，英文 rank 奇偶不同，两种语言的字符范围不同；四个位置互斥。随机量不会因为模除、长度筛选或生成后重试而丢失标称熵。

英文通过长度多项式和 Newton 恒等式精确计数不同主体的四个分句；测试另用显式公式 `P1^4 - 6P1²P2 + 3P2² + 8P1P3 - 6P4` 独立重算，并以小型全量枚举核对。中文计数由独立循环重算语义限制。所有计数使用 BigInt，不转为浮点数。

最多 5 次猜测时，未看到当前有效句子的盲猜上界：中文 `5/2^80 ≈ 4.14×10^-24`，英文 `5/2^64 ≈ 2.71×10^-19`。是否接受仍取决于当前用户、确切会话、UID、挑战 ID、选中候选及实时公开签名，不因一句话属于词库而接受。

“1,000 条不重复”只是回归检查；熵值依据是完整约束空间的精确计数和映射单射证明。

## 复现

```sh
node scripts/bilibili-audit-samples.mjs
node --test tests/bilibili-encoder.test.mjs tests/bilibili-candidates.test.mjs
```

样本使用固定公开种子复现，与生产随机挑战无关。报告记录源文件和样本 SHA-256，CI 检查它们一致。任何词条、顺序、禁配、模板或映射改变都必须换版本并重新生成报告。生产生命周期与部署见 [B站签名绑定](bilibili-binding.md)。
