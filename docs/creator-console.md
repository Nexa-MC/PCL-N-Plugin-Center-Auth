# 创作者控制台

账户中心的“创作者控制台”位于 `/account?section=creator`，`/creator` 可直接跳转。已完成注册并接受当前条款的有效登录账户，可点击申请立即开通。

`POST /auth/v1/applications` 接受 `{kind:"creator"}`。服务端在同一 D1 事务中写入已批准的申请、授予 `users.creator=1`、记录 `creator.auto_granted` 审计。审核人标记为 `system:creator`。并发与重复提交只产生一次授予；已开通时返回已有结果。客户端不能指定目标账户或其他权限字段。

创作者资格是独立角色，随会话和账户导出返回；账户删除时清除。控制台显示真实资格状态并提供创作指南与商店入口。管理后台用户列表可查看创作者角色。创作者自动申请不进入人工待审队列。

迁移扩展原申请类型 CHECK 约束，完整保留原申请 ID、状态、审核记录、核心贡献者申报、GitHub 绑定字段和待审唯一索引。它不迁移或批准其他类型的待审申请。
